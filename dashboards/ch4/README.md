# 第四章交互面板使用说明

这个面板用四组数据，讲述LLM格局变化时期的评测、供给、人才和企业应用。网页为英文，本文用中文解释。制作与打包日期：2026年11月3日。

## 1 如何打开

1. 把ZIP完整解压到任意文件夹。
2. 双击 `index.html`，用Chrome或Edge打开。
3. 不需要联网、安装软件或运行代码。网页已内置全部作图数据。

电脑上四块图同时显示；窄屏或较矮屏幕会出现四个图表标签，点击切换。页面无需上下滚动，模型选择列表可以在弹出框内滚动。

## 2 界面怎么看

最上方是标题，下一行选择时间。四张数字卡概括当前窗口：专有模型评价份额、HF新增仓库合计、美国企业AI采用率和所选国家人才净流入指标。下方四块图各讲一件事。

| 英文标题 | 大白话含义 | 用到的数据及作用 |
|---|---|---|
| 01 Evaluation share & supply | 专有模型的评价份额与模型平台的供给怎样变化 | Chatbot Arena榜单记录评价次数，用来算专有模型占比；HF季度新增仓库，用来看供给规模 |
| 02 Model exposure | 哪些具体模型在对战中出现得多 | Chatbot Arena 140k公开对战样本，用来看每周模型出场份额及样本量 |
| 03 Talent netflow | 各国人才净流入指标怎样变化 | AI Index人才月度数据，用来看一个国家的变化和同月国家差异 |
| 04 Business AI adoption | 美国企业使用AI是否更加普遍 | Census BTOS企业调查，用来看实际采用比例；Epoch模型日期提供时间参照 |

“专有模型”在这里按榜单的Proprietary标签识别，可简单理解为模型权重不公开的模型。HF是Hugging Face模型分享平台；仓库可理解为模型的存放页面。

## 3 全部操作与联动

| 控件或动作 | 怎么操作及会发生什么 |
|---|---|
| 两个日期框 | 自选开始和结束日期，全部图与数字卡一起更新 |
| 2024–25 | 回到主线窗口2024年1月至2025年12月 |
| Battle window | 查看2025年对战窗口；日期按完整周桶设置为4月14日至7月27日，真实观测为4月17日至7月24日 |
| All dates | 看全部时间，范围2023年1月至2026年9月，各图只显示有数据的部分 |
| Reset | 恢复默认时间、美国、Top 5模型，以及默认开关状态 |
| 鼠标停在图上 | 查看最近观测点的日期、数值和说明，不改变筛选 |
| 点击时间图 | 选择一个日期，弹出其他指标附近时间的记录，并显示定位线。日期可能不完全相同，以标出的实际日期为准 |
| Clear × | 清除日期定位；保留当前时间范围和其他选择 |
| 按住鼠标横向拖选 | 缩小全局日期范围，全部视图同步更新。手机建议直接使用日期框 |
| Fixed 61 | 打开或关闭固定61个模型的虚线，比较同一批模型的结果 |
| Models | 搜索、勾选具体模型，最多同时比较8个；Top 5恢复默认，Clear清空曲线 |
| Full weeks | 去掉首尾两个不完整周；曝光份额、样本量和双差率重新计算 |
| 国家下拉框或国家条形 | 切换人才折线和人才数字卡；点击人才折线的月份，还能切换同月国家横截面 |
| 90% interval | 开关企业采用率旁的浅色阴影，表达调查估计的误差范围 |
| Events | 开关模型日期竖线与事件列表；点击事件按钮，按日期跨图定位 |
| 小屏顶部图表标签 | 在四部分之间切换，保留相同时间范围和筛选状态 |

**记忆方法：选时间，全页一起变；点日期，一起看附近记录；选模型，只改曝光图；选国家，只改人才部分。**

国家切换不会改变美国企业调查，模型切换也不会把全国采用率变成某个模型的采用率。点击定位不会缩小时间范围，拖选或修改日期才会。

## 4 为什么要选择不同时间

就像看相册，可以看全部，也可以只看某一年。不同数据覆盖时间不同：榜单到2026年9月；面板中的HF季度供给覆盖2024—2025年；对战只有2025年4—7月；人才到2025年9月；企业调查参考期到2025年9月21日。因此切换到2026年后部分图空白，表示没有对应时期的数据。

默认2024—2025窗口下，企业采用率从5.3%到10.0%，美国人才指标从207.92到26.00；点All dates后，才会看到更早的企业3.7%和人才320.42。不要把不同时间范围的起点混用。

数字卡中，HF是所选季度新增数量的合计，其他三张主要显示窗口最后一个有记录的值，并与首期比较。默认HF合计1,932,566个，即2024—2025八个季度新增量之和，不是平台累计总存量。

## 5 每部分的趋势与主题故事

本章服务的主题是“LLM前沿格局向专有模型主导变化”。四部分的作用不同：第一部分直接展示评价份额，第二部分展开具体模型竞争，第三、第四部分提供人才与需求背景。

### 图01 专有评价份额提高 平台供给扩大

**趋势：** 2024Q1至2025Q4，专有模型的记录评价份额从50.28%提高到56.17%，增加5.89个百分点；2024Q2曾下降，之后总体回升。延长到2026Q3，达到60.37%。固定61模型对照在2024—2025年从50.74%提高到64.23%。

同期，HF季度新增模型仓库从118,252个增加到332,098个，中间有起伏。2024年度新增751,702个，2025年度新增1,180,864个。

**含义与结论：** 专有模型在评测记录中的份额提高，与HF模型供给扩大同时发生。主题可以讲成“专有模型份额上升，开放平台继续发展”，而不是把生态变化理解成平台上不再有新模型。

**讲解一句话：** “评测中专有模型的份额提高，同时模型分享平台仍不断增加新供给。”

### 图02 高频模型的曝光份额出现起伏

**趋势：** 默认五个模型合计周曝光份额，在2025年6月2日所在周达到28.03%，之后波动回落，末周为13.94%。末周并非完整周，可勾选Full weeks检查完整周结果。全窗口五模型合计出场47,190次，占所有模型双侧出场的17.40%。

默认五个模型按整个窗口的出场次数选定，不会随日期筛选自动更换Top 5；早期它们尚未在样本出现，曲线留空。整批数据包含53个模型、135,624场有效对战、271,248次双侧出场。双差15,754场，占11.62%，表示两边回答都不好。

**含义与结论：** 不同模型的曝光份额会随时间调整，竞争结构持续变化。它为“前沿格局变化”补充具体模型层面的细节；这张图本身没有给所有模型分类为开放或专有，不能单独据此判断两类模型的总体转移。

**讲解一句话：** “具体模型的展示机会一直在变化，并不是同一批模型始终获得相同关注。”

### 图03 美国人才净流入明显放缓

**趋势：** 选择All dates并选择United States，可见人才净流入指标从2023年1月的320.42降到2025年9月的26.00，下降约91.9%，末期仍为正。

**含义与结论：** 美国仍保持人才净流入，但净流入指标明显减弱。这为LLM竞争格局变化提供国家层面的人才环境背景；它不是企业之间人员跳槽的记录，也不表示美国人才总量下降91.9%。

**讲解一句话：** “LLM竞争变化的同时，美国人才净流入放缓，但仍然保持净流入。”

### 图04 企业使用AI的比例总体提高

**趋势：** 在完整调查窗口内，美国企业AI采用率从3.7%升至10.0%，增加6.3个百分点，期间存在短期波动。默认2024—2025窗口展示5.3%至10.0%。

**含义与结论：** 越来越多美国企业把AI用于生产或服务。LLM格局变化发生在AI需求总体扩大的背景下，为主题补充应用落地这一面。调查问的是广义AI，事件日期帮助观察技术发展的时间位置。

**讲解一句话：** “竞争格局变化的同时，企业使用AI的范围也在扩大。”

### 四图合起来怎么说

“专有模型在评测中的份额提高，同时HF模型供给扩大；具体模型的曝光份额不断调整；美国人才净流入放缓但仍为正；企业AI采用率总体上升。四张图从评测格局、模型竞争、人才环境和应用需求四个角度，呈现LLM生态的变化。”

## 6 两分钟演示顺序

1. 点Reset讲图01：50.28%到56.17%，同时HF供给扩大；开关Fixed 61看看对照。
2. 点Battle window讲图02：看各模型周出场份额和下面的样本量；展示一次Models选择。
3. 点All dates讲图03与图04：美国人才320.42到26.00，企业采用3.7%到10.0%。
4. 点击一个日期，展示跨图定位；最后Reset返回默认布局。

## 7 数据文件与计算口径

| 文件 | 内容 |
|---|---|
| `index.html` | 英文单屏面板，已内置全部作图数据 |
| `data/dashboard_data.json` | 与网页内嵌数据完全一致的完整副本 |
| `data/quarterly_share_supply.csv` | 11个季度的快照日期、模型数、专有评价份额、固定集合份额和HF供给 |
| `data/weekly_model_exposure.csv` | 15周×53模型，共795条，包含出场数、周分母、份额与该模型是否处于样本观测期 |
| `data/weekly_battle_totals.csv` | 每周有效对战数、双侧出场数、双差数、真实覆盖日期及不完整周标记 |
| `data/models.csv` | 53个原始模型名与顺序编号 |
| `data/talent_monthly.csv` | 21个国家/地区的674条月度人才指标 |
| `data/business_adoption.csv` | 54期全国采用率、标准误、区间和参考日期 |
| `data/model_events.csv` | 当前页面使用的六个模型事件 |
| `data/hf_quarterly_source.csv` | HF原始季度图源，包括2022—2025年；网页展示其中2024—2025年 |
| `manifest.json` | 文件大小与SHA256校验值 |

这些文件包含网页所用的全部汇总数据；不包含原始对话文本和整套原始排行榜快照。对方可以直接使用和核对全部图表，无需1.6GB原始对战文件。HTML内置数据，不依赖外部CSV读取；修改CSV不会自动改变页面。

评价份额＝同一快照中Proprietary模型记录评价次数÷全部模型记录评价次数。该指标不是获胜比例。曝光份额＝某模型当周出场次数÷全部模型当周出场次数，每场两次出场。模型选择不会改变全模型分母。

按来源时间键筛选：榜单按实际快照日、HF按季度末、人才按月初、对战按周一、采用率按参考期起始日，保留完整观测，不拆成每日数值。国家缺月不补零；JSON中的null表示缺失。曝光CSV记录的零表示没有样本出场，不能自动理解成模型尚未上线。

来源：Chatbot Arena leaderboard及arena-human-preference-140k；Stanford AI Index图源fig_1.5.6和fig_1.8.6；美国Census BTOS AI Core Questions；Epoch notable AI models。数据来自团队已保存的本地文件，并非实时联网更新。人才指标保留源数值，原报告单位脚注仍待进一步核对。
